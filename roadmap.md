# Roadmap

This roadmap prioritizes privacy and usefulness over integration count.

## Phase 1 — personal workflow

- Unified today and seven-day views
- Manual and recurring events
- Schedule-file import
- Dedicated-inbox review queue
- Parent-approved events and tasks
- Important-change feed
- Basic overlap detection

## Phase 2 — safer connectivity

- OAuth for supported accounts
- Narrow, parent-selected calendar connections
- Clear source-level enable and disable controls
- Export, backup, and deletion controls
- Better exception handling for recurring schedules

## Phase 3 — local intelligence

- Improved deterministic parsing
- Local entity matching for child, activity, and location
- Travel-time and transportation-gap awareness
- Explainable confidence and uncertainty indicators

## Phase 4 — carefully bounded AI exploration

Before any external model is considered:

1. Remove or tokenize direct identifiers.
2. Send only the minimum excerpt required for the task.
3. Verify retention, training, deletion, and subprocessors contractually.
4. Preserve parent review and provide a non-AI path.
5. Revisit the threat model and public privacy claims.

## Not currently planned

- Advertising based on family or child data
- Selling or sharing family data
- Building a public child profile
- Automatic actions without parent visibility
